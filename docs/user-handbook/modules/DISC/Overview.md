# Bài test DISC

Module `Bài test DISC` dùng để người dùng thực hiện bài trắc nghiệm DISC trực tiếp trên hệ thống.

## Cách truy cập

Từ menu trái, chọn `Bài test DISC`.

Hệ thống mở màn làm bài với tiêu đề `Bạn là người như thế nào?`.

## Các phần trong module

- [Làm bài test DISC](LamBaiTestDISC.md)
- [Lưu ý vận hành](LuuYVanHanh.md)

## Phạm vi sử dụng hiện tại

Handbook này chỉ ghi nhận luồng đang có trên UI hiện tại:

- Người dùng trả lời từng câu hỏi DISC.
- Hệ thống tính kết quả sau câu cuối.
- Kết quả được lưu tự động cho tài khoản đang đăng nhập.

Không có màn danh sách lịch sử kết quả DISC được ghi nhận trong luồng UI hiện tại của module này.
