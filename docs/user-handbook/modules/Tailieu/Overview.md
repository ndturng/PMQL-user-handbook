# Tài liệu

Module `Tài liệu` dùng để quản lý thư mục tài liệu, tải file lên thư mục và chia sẻ tài liệu/liên kết cho chi nhánh được phép xem.

## Cách truy cập

Từ menu bên trái, bấm `Tài liệu`.

Màn hình chính hiển thị danh sách thư mục tài liệu mà tài khoản hiện tại được phép xem.


## Luồng sử dụng chính

- [Quản lý thư mục tài liệu](./QuanLyThuMuc.md)
- [Quản lý file và liên kết trong thư mục](./FileLienKet.md)
- [Lưu ý vận hành](./LuuYVanHanh.md)

## Quyền thao tác

Tùy quyền tài khoản, người dùng có thể chỉ xem danh sách, hoặc có thêm quyền tạo thư mục, cập nhật, xóa, upload file và chia sẻ.
