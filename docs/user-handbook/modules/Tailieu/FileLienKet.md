# Quản lý file và liên kết trong thư mục

## Mở danh sách file trong thư mục

Từ màn `Tài liệu`, bấm tên thư mục cần xem.

Màn hình thư mục hiển thị danh sách file/liên kết với các cột:

- `Tên files`
- `Dung lượng file`
- `Ngày cập nhật`
- `Chức năng`


## Upload file vào thư mục

Trong màn hình thư mục, bấm `UPLOAD FILE`.

Modal `Upload File` mở ra.


Bấm vùng `Chọn nhiều file upload !`, chọn một hoặc nhiều file từ máy tính. Hệ thống tự tải các file đã chọn lên thư mục và đóng modal sau khi hoàn tất.

## Thêm liên kết chia sẻ

Trong màn hình thư mục, bấm `SHARE LINK`.

Modal `Chia sẻ Liên kết` mở ra.


Nhập thông tin liên kết theo các trường đang hiển thị trên modal, sau đó bấm `Thêm Mới` để lưu.

## Tải file hoặc mở liên kết

- Với file upload, bấm nút tải xuống ở cột `Chức năng` để mở/tải file.
- Với liên kết, bấm nút liên kết ở cột `Chức năng` để mở link trong tab mới.

## Sửa tên file hoặc thông tin liên kết

Tại dòng file cần sửa, bấm biểu tượng bút chì cạnh tên file.


Modal `Sửa tên file` mở ra.


Cập nhật thông tin cần sửa, sau đó bấm `Cập nhật thông tin`.

## Xóa file hoặc liên kết

Tại dòng file/liên kết cần xóa, bấm nút biểu tượng thùng rác ở cột `Chức năng`.


Hệ thống hiển thị hộp thoại xác nhận.


Chỉ xác nhận xóa khi chắc chắn file hoặc liên kết không còn cần dùng.
