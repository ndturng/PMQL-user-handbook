# Cài đặt

Module `Cài đặt` dùng để quản lý các thiết lập vận hành đang có trên UI:

- `Ngày nghỉ`
- `Khuyến Mãi`

## Cách truy cập

Từ menu bên trái, bấm `Cài đặt`.

Màn hình `Cài đặt` hiển thị các thẻ chức năng `Ngày nghỉ` và `Ưu Đãi`.


## Luồng sử dụng chính

- [Cài đặt ngày nghỉ](./NgayNghi.md)
- [Cài đặt khuyến mãi](./KhuyenMai.md)
- [Lưu ý vận hành](./LuuYVanHanh.md)

## Thanh chức năng trong module

Trong các màn con của `Cài đặt`, thanh chức năng phía trên có lối tắt đến:

- `Ngày nghỉ`
- `Khuyến Mãi`
